Benito's Hidden Treats

Click a paw to see what's underneath! 🐾

Click the treat to cover it with the paw again!

This page was made with the assistance of ChatGPT. I asked the bot to write html for a page that includes pictures of paws that flip over to reveal treats when clicked. The first time it ran the command it generated an entire downloadable page with elements similar to what I had coded, but not taking my actual written code into account. The second time I asked it to use the most basic code possible and I was extremely exact about the visual styling of the content. It was most helpful when I wrote shorter, hyper-specific prompts, however this was the most tiem consuming method. After this exercise I would argue that the use of ChatGPT should be restricted to troubleshooting code rather than writing it from the very beginning, particularly for those that have just started learning to code.
